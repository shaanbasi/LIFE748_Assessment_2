# LIFE748 Assessment 2

Code and analysis files associated with LIFE748 Assessment 2 -

## Repository structure

### Part 1 - Genome assembly and annotation
Genome assembly, quality assessment and genome annotation workflow.

- `Part1_analysis.sh` - command-line workflow for genome assembly and annotation.
- `Part_1_results.R` - generation and summarisation of Part 1 results.

### Part 2 - Machine learning analysis
Differential-expression analysis and supervised machine-learning classification.

- `Assessment2_ML_1.qmd` - complete R/Quarto analysis including differential expression, feature selection, clustering and classifier evaluation.

### Part 3 - Protein sequence and structural analysis
Identification and structural investigation of selected transcriptional regulators.

- `Part_3_BLAST.sh` - BLASTP-based identification of GN3 homologues of selected *E. coli* K-12 transcriptional regulators.

Protein structures were predicted using ColabFold/AlphaFold2 and structural similarity was assessed using Foldseek.
